# MAME Smart ROM Sorter v5.0 — GitHub Release Notes

MAME Smart ROM Sorter v5.0 is a cleaner, more polished release focused on helping arcade builders curate usable MAME folders from ROM sets they already own.

## Download

Attach these files to the GitHub release:

1. `MAME_Smart_ROM_Sorter_v5.0.exe`
2. `MAME_Smart_ROM_Sorter_v5.0_Source.zip`
3. Optional: `SHA256SUMS.txt`

## Recommended release title

`MAME Smart ROM Sorter v5.0 — Stop Sorting ROMs Manually`

## Suggested GitHub release body

MAME Smart ROM Sorter v5.0 helps home arcade builders filter and organize MAME ROM sets into cleaner, purpose-built folders.

This release focuses on usability, presets, cabinet-friendly workflows, and a cleaner public package.

### Highlights

- Cleaner v5.0 GUI/source structure.
- Preset-driven sorting workflow.
- Cabinet/controller-focused organization goals.
- Better release packaging for GitHub users.
- Clear public disclaimer: this tool does not include or download ROMs.

### Important

This tool does not include ROMs, BIOS files, CHDs, samples, or game downloads. You must use your own legally obtained files.

For best results, use a non-merged MAME ROM set.

### Feedback

Feedback from v5.0 will help shape v5.5, including possible improvements to cabinet presets, display/orientation filters, regeneration helpers, and plain-text include/exclude lists.
